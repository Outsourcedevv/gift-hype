Add the overlay in TikTok LIVE Studio

  

    

    
    
      
  1. In LIVE Studio, under Sources, press + (Add source) and pick Link.
    2. 
      
  2. Click in the address box and press Ctrl + V: the overlay's address is already copied.
    3. 
      
  3. Set the size to 1920 × 1080 (or Fit to screen) and press Add.
    4. 
      
  4. Drag it to the top of your sources so the popups show over the game.
    5. 
    

    
The address points back to this PC, so Gift Hype must be open while you stream. If the overlay shows as a tiny box or stops updating, add ?refresh=1 to the end of the address.
